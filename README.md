MyRestaurant: A Traditional Afghan Culinary Experience
A modern, responsive multi-page web application designed to showcase authentic Afghan cuisine through a clean user interface and interactive features. This project was built to demonstrate proficiency in front-end development, responsive design principles, and collaborative engineering.

 Key Features
Responsive Architecture: A fully fluid layout that adapts to mobile, tablet, and desktop views using Flexbox and CSS Media Queries.

Cinematic Hero Section: High-impact, full-width visual storytelling with centered call-to-action (CTA) elements.

Interactive Menu Grid: A structured showcase of traditional dishes using modern CSS card components.

Dynamic Cart Logic: An integrated shopping cart that tracks user selections in real-time.

Global Accessibility: Implementation of the Google Translate API to support international users.

 Technical Stack
Languages: HTML5, CSS3, JavaScript (ES6+).

Icons & Typography: FontAwesome for iconography and Google Fonts (Playfair Display & Segoe UI) for a premium aesthetic.

Version Control: Managed and deployed via Git and GitHub.

📝 Developer Notes
To ensure a smooth user journey, we implemented specific interface logic:

Smart Checkout: The "Proceed to Checkout" button is programmatically managed; it remains inactive until the user adds items to the cart, ensuring a logical flow from selection to purchase.
